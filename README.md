# NasPy - A Python Wrapper for NASCAR Data
A tool intended to allow users to interface with NASCAR-provided data endpoints in a simplified manner.

## Available Data
- 🏁 Race and stage results dating back to 2017 and 2020 respectively
- 🏎️ Race information and scheduling
- ⏱️ Driver lap times from race, qualifying, and practice sessions
- ⛽ Pitstop data and performance
- 🟨 Cautions, flag data, and lap notes
