# NasPy - A Python Wrapper for NASCAR Data
Designed to help make NASCAR data analytics **easier**! The goal of NasPy is to make interacting with provided NASCAR data endpoints as easy as possible.

## Some of the Data Available
- 🏎️ Race information and scheduling
- 🏁 Race and stage results dating back to 2017 and 2020 respectively
- ⏱️ Driver lap times
- ⛽ Pitstop data and performance
- 🟨 Caution and flag data
